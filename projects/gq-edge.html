Graph Quantizer Edge Deployment

2025–2026 · backend deployment owner

Deployment-ready graph quantization across ExecuTorch XNNPACK, Qualcomm QNN, and Arm Ethos-U — constraints as data, upstream fixes over local patches.

What I did

  • Built the dynamic-quantization path producing bit-identical results to torchao's XNNPACK reference, and generalized backend limitations into a declarative constraints system applied by a common engine.
  • Set up quantize→lower→run integration testing for XNNPACK, QNN, and Ethos-U (Docker + FVP), catching the "quantized fine, breaks at lowering" gap in CI.
  • Diagnosed "quantization made it slower" down to delegate-boundary convert cost by inspecting PTE flatbuffers; folded asymmetric pads into enlarged conv kernels (bit-exact), cutting XNNPACK convert nodes 10→2 and Raspberry Pi 5 latency by ~23% in a static-quantization benchmark.
  • Fixed root causes upstream instead of patching locally — ExecuTorch XNNPACK quantizer/delegation fixes (4 merged PRs), a DeiT transpose q-param mismatch, and QNN per-channel-group support (open PRs).
